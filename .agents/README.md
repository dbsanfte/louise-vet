# Repository agent resources

Start with root [AGENTS.md](../AGENTS.md), then the authoritative
[master game design](../docs/game-design.md). This directory holds reusable
workflow aids for agents working in this repository.

- [Design change checklist](design-change-checklist.md): feature planning and review.
- [README](../README.md): development, containers, Blender, and verification.
- [Asset credits](../docs/assets.md): asset provenance and licenses.

Keep product decisions in the master design and repository rules in AGENTS.md.
Do not store alternate specifications, chat transcripts, credentials, or local
state here. These are supporting Markdown documents; creating this directory
does not configure an agent extension or chat storage.
